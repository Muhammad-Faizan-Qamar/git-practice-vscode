# 📝 React ToDo App

A modern, frontend-only ToDo application built with React and Vite.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks (Double-click on task to edit)
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🔍 Filter tasks (All / Active / Completed)
- 💾 Data persistence using LocalStorage (data saves even after refreshing the page)

## 🛠️ Tech Stack

- React (Frontend Framework)
- Vite (Build Tool)
- CSS (Styling)

## 🚀 How to Run Locally

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`
